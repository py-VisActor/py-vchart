# 核心笛卡尔图表批次验收

本批按照 VChart 2.2.1 的系列坐标系和 chart transformer 划分范围。共 12 个核心笛卡尔图种，另纳入 common 在单绘图区内组合笛卡尔系列的用法。linearProgress 使用笛卡尔坐标，虽默认隐藏轴，也在本批。扩展包、统计规格编译器、极坐标图种另行排期。验收覆盖下列静态配置。

| 图种 | 已对照的行为 | 用例数 |
| --- | --- | ---: |
| bar | 原有单系列，加二维分类字段分组、按类别分开累计正负堆叠 | 10 |
| line | 分类轴折线、缺失值断开、横向、圆点、隐藏点、自定义线色与宽度 | 6 |
| scatter | 分类/数值 X 轴、配对数值轴、半透明重叠、406 条汽车观测 | 8 |
| area | 分类轴与零线围成的静态面积、顶边折线、默认点、缺值断开、空集 | 3 |
| rangeArea | 两个区间字段共用一条轴、垂直/水平色带、空集 | 3 |
| rangeColumn | 区间两端决定矩形边界、垂直/水平、空集 | 3 |
| histogram | 输入预分箱起点、终点和频数，不等宽区间，两个方向、空集 | 3 |
| waterfall | 逐项增减、末端总计、虚线连接、显示/隐藏变化值标签、空集总计 | 3 |
| boxPlot | 五数摘要、箱须与中位线、垂直/水平、离群点单独绘制并参与值域、空集 | 4 |
| heatmap | 两条分类轴、稀疏格子、默认离散配色和两端线性颜色映射、空集 | 4 |
| mosaic | 单类别一条记录、正权重累计分配宽度、显式 bandWidthField、空集 | 3 |
| linearProgress | 隐藏轴、固定轨道和进度矩形、垂直/水平、空集 | 3 |
| common | 单绘图区柱线组合、联合值域、独立右侧数值轴及 seriesIndex 绑定、空集 | 4 |

**批次结果。** 13 个入口、57 个输入，由同一候选版本一次运行。固定 npm 2.2.1、Chromium 158 的无头参考环境，57 张原图和 57 份参考场景均经过独立重采并逐字节匹配。用同一个 Python wheel 在单独安装目录重跑全部输入，57 张候选 PNG 与开发目录输出逐字节一致。已有的 22 个柱、线、散点用例另与上批 Python 输出逐张核对，PNG 字节一致。环境为 Windows、CPython 3.13、py-skia-canvas 0.1.0a19 CPU。

## 统一校验与修复

1. 每个输入先核对 spec 和参考 PNG 的哈希，再从公开入口生成场景与 PNG。场景对比包含绘图区、轴域、范围、标签及锚点，并按类型核对区间端点、矩形边界、面积上下沿、箱线统计量、异常点或组合系列几何。数值绝对误差上限为 1e−6。
2. 修复横向直方图的分箱轴方向、进度图的隐式轴创建顺序、空瀑布图的总计记录；热力图参考采集器按真正的矩形单元取得尺寸，避免把中心点误当成单元边界。
3. 整批比较解码 RGBA。保持原有平坦区域精确匹配及全图误差上限。瀑布图默认变化值标签使用 14px 黑字，在当前字体环境实测有 10 个像素的最大通道差超过 120。仅该案例的四个字形邻域放宽局部峰值至 160（实测 158）；标签文字、位置、平坦像素、区域外峰值和全图统计仍独立校验。[局部差异配置](../tests/cases/waterfall/with-labels/pixel-policy.json)
4. 构建产物验证通过。18 个 unittest 测试通过，其中一次完整批次测试覆盖全部 57 个参考输入；额外断言覆盖双轴更新、正负堆叠、变宽分箱及空集总计。

## 复现

```powershell
python -m pip install -e ".[render,test]"
python tools/visual/check_cartesian.py --batch cartesian
python -m unittest discover -s tests -v
```

全批输出位于 `test-runs/cartesian-batch/`。用浏览器打开 `index.html` 查看每例的上游图、Python 图和差异图。汇总 `report.json` 可按图种定位失败案例；用 `--type rangeArea` 等参数可单独重跑。开发侧参考工具使用 VChart 原生 getDataURL 导出，mosaic 按上游要求显式注册。输入及固定基准见[测试用例](../tests/cases)。

**兼容边界。** 本次是各图种静态基础配置的验收。common 当前覆盖同一绘图区内的柱线系列；多绘图区、任意系列混合、曲线插值、自动原始数据分箱、复杂分组马赛克、自定义瀑布总计及高级坐标轴选项仍待后续对照。支持情况应以具体变体与基准为准。
