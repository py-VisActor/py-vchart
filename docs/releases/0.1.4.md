# py-visactor-vchart 0.1.4

This release aligns the py-VisActor macOS packages at version 0.1.4. The macOS installation uses Canvas 0.1.4. Use native CPython 3.13 on macOS 13 or later.

```sh
python -m pip install py-visactor-vchart==0.1.4
```
