# py-visactor-vchart 0.1.1

提供全部 68 个二维静态图表入口的公开 Canvas 渲染与多格式导出，供独立 Python 使用和 py-mermaid 集成。既有 v0.1.0 及其发行文件保持不变。

- 默认文本、pictogram SVG 和词云蒙版经公开 py-skia-canvas API 绘制；skia-python 移至可选 `reference` 依赖。NumPy 保留用于数据与数值计算。
- 支持 Canvas 0.1.0a18～0.1.0a19；可与正式 py-visactor-katex 0.1.0 共用 a18。
- `VChart.supported_types()`、`to_buffer()`、`draw_to()` 公开类型清单、PNG/JPEG/WebP/SVG/PDF 与同 Canvas 图表合成；保留 `render().to_png()`。
- 提供真实 cpu/auto/gpu 选择与实际 engine 信息，实例 maps/SVG 离线资源隔离。
- 旧 calibrated reference 路径仍可显式使用，既有 225 例严格对照阈值不降低。Canvas 原生字体的正常度量/栅格差异单列，不声称与 reference 完全逐像素相同。

范围为当前包实际支持的二维静态类型及各类型已列选项。3D、交互、动画和完整 VChart JS 高级选项不在此版本范围。Python 版本为 CPython 3.13，发行矩阵为 Windows/Linux x86-64、Canvas a18/a19。

发行验收与实际发布结果另记于 `docs/RELEASE_0_1_1.md`，不从本说明或源码完成状态推定通过。
