# py-visactor-vchart 0.1.3

Adds support for static chart rendering on macOS 13 and later on Apple Silicon and Intel. The CPython 3.13 installer selects the matching Canvas dependency for macOS, Windows AMD64, or Linux x86_64 with glibc 2.28 or later.

```sh
python -m pip install py-visactor-vchart==0.1.3
```

The package continues to provide 68 two-dimensional chart types with PNG, JPEG, WebP, SVG and PDF exports.
