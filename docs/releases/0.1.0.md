# py-vchart 0.1.0

首个正式版提供 VisActor VChart 的原生 Python 二维静态渲染。支持 68 个公开图表入口，涵盖内置图、二维扩展图、统计规格和词云。通过 `VChart(spec).render().to_png()` 导出 PNG。

发布环境为 CPython 3.13、Windows x86-64 和 Linux x86-64。包安装时自动安装 `py-skia-canvas==0.1.0a19`、`skia-python==144.1` 和 NumPy。项目使用 MIT 许可，所含移植代码的许可随发行包保留。

原生 VChart 2.2.1 的 Chromium 截图作为对照。225 个静态用例的场景与图片均通过既有验收规则，另有 31 项单元测试。测试重点和输入边界见 [批量验收记录](../EXPANDED_BATCH_ACCEPTANCE.md)。

范围集中于二维静态图。分组 pairPlot、storyline 图片卡片、pictogram 嵌套 SVG、词云形状蒙版已覆盖。交互、动画、DOM 和三维图表不在本版范围。复杂蒙版布局、更多 storyline 布局与未列入验收的高级样式仍需逐项对照。

GitHub Release 附带 wheel、源码包及 SHA-256 清单。用户可按 README 中的 wheel 地址安装。
