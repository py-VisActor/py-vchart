# Python VChart 静态移植计划

状态：设计阶段。上游固定为 VChart 2.2.1，提交 `fdb63276cf8b71f5a6cca128c409e009cc94615a`。本文确定 Python 实现范围与代码归属；[架构分析](VCHART_ARCHITECTURE.md)用于查上游行为，[逐图迁移与验收规程](PORTING_WORKFLOW.md)用于执行。目录随首个有用例的实现创建。

## 交付边界

目标是从 VChart 的声明式 spec 和本地数据生成确定的静态图像。先交付离屏 PNG。沿用上游图种名、字段名、系列与区域关系、主题和样式的优先级；Python 代码内部使用 snake_case。保留当前 src 布局、发行名、导入名和 unittest 入口。

- 纳入静态轴、图例、标签、标题、注释、裁剪、文字测量、初始可见范围和普通态样式。数据替换或尺寸变化可以通过重新渲染比较结果。
- 忽略事件、命中测试、悬停/选中态、tooltip、拖拽缩放、动画、时间线播放、DOM、HTML 覆盖层、CSS 选择器和窗口监听。动态字段可与合法静态字段共存；只读静态字段，纯动态配置的有无应产生相同静态输出。
- 混合功能按字段拆分。例如图例保留符号、文字与布局，忽略点击筛选；预设筛选范围若改变首帧数据，要保留范围语义。依赖 DOM 回调才能产生的静态内容标为范围外。首批输入限可序列化 spec 和本地资源。
- 对尚未支持、但会改变静态画面的图种或选项，返回含 type 和字段路径的明确诊断；禁止悄悄画成近似图种。动态字段单独列入忽略清单。

## 目标代码结构

下列树是目标位置。小图种先用单文件，需要拆分时再建同名子包。

```text
src/py_vchart/
  __init__.py        # 公开入口，保留现有版本接口
  core/              # VChart 实例、静态渲染流程、类型注册、诊断
  chart/             # 图种与 spec transformer，含 cartesian、polar、common
  region/            # 系列归属、绘图区和裁剪范围
  series/            # 每种系列的数据字段、视觉通道和 Mark 组合
  data/              # VChart 的字段统计、堆叠、图种数据转换适配
  scale/             # 图表级比例尺、跨系列 domain 与颜色协调
  layout/            # 标题、轴、图例、区域的占位和测量反馈
  component/         # 静态轴、图例、标签等模型
  mark/              # 图元编码，记录与图形的对应关系
  theme/             # 缺省值、配色和样式合并
  compile/           # 组织测量、布局、图元求值、场景提交和导出
  _deps/
    vdataset/        # 具名视图、解析与派生变换的执行
    vscale/          # band、linear 等独立映射及刻度运算
    vlayouts/        # 依图种加入专用几何算法，如 sankey、treemap
    vrender/         # 静态图形、分组、边界、测量及绘制接口
      backends/      # 首选 py-skia-canvas 离屏适配器
tests/
  unit/              # 纯算法、配置转换、独立图元
  integration/       # 从公开入口输入 spec，验证结果和诊断
  cases/<type>/<id>/ # 共享输入、元数据和上游基准
tools/
  oracle/            # 只在开发时运行固定版本上游
  visual/            # 生成候选图、比较、报告
test-runs/            # 每次运行的候选图、差异图与日志
```

**依赖方向。** core 调度 chart 和 compile；chart 组装 region、series 和 component；series 通过图表层 data、scale 或专用变换获取数据与几何，再用 mark 描述画什么；compile 将图元交给静态 vrender。图表层可导入所需的 _deps，_deps 禁止反向导入具体图种。四个依赖模块通过记录、数值、几何或绘图接口交换结果。同目录其他项目通过包接口使用，禁止依赖开发机上的相对源码路径。

**归属判据。** 堆叠起止值属于 data，执行已注册变换属于 _deps/vdataset；选取多个系列的联合值域属于 scale，domain 到 range 的映射属于 _deps/vscale；给轴留空间属于 layout，给桑基节点分配坐标属于 _deps/vlayouts；将负值编码为柱体属于 series，绘制已有坐标的矩形属于 _deps/vrender。后端提供文本测量与绘制，两者使用同一字体配置。

**按需迁移。** 每个依赖能力必须关联一个消费图种、一处固定上游符号、输入输出和一个测试。仅在第二个图种具有相同语义时抽取共享的图表层逻辑。优先自行实现小而明确的行为；移入源码、测试或素材时记录仓库、提交、路径、许可证及必要声明。核心保留 Python ≥3.11；首个候选渲染环境采用 CPython 3.13，以可选依赖接入 py-skia-canvas，基线建成后记录实测版本。

## 按图种推进

每行是有先后依赖的批次。**每批按类型逐个验收**；批次结束时用同一候选版本重跑已有全部静态案例。核心包 28 个顶层类型在下表各出现一次。每类只对已列入测试的变体宣称支持。

| 批次 | 图种及顺序 | 本批新增的共享能力 | 代表性验收 |
| --- | --- | --- | --- |
| 0 基线 | 选正负双柱作首例 | 固定上游离屏输出、字体、场景快照、像素比较器；先验证同端重复输出 | 缺柱、错色、移动一根柱的故障注入必须能让比较失败 |
| 1 首条完整路径 | `bar` | 单区、band/linear、矩形、静态轴、文字测量、零基线 | 垂直与水平、正负值、空数据；缺省轴与显式轴 |
| 2 笛卡尔系列 | `line` → `scatter` → `area` → `rangeArea` → `rangeColumn` | 点、折线、闭合区域、上下界、缺值；扩展柱的分组与堆叠 | 断点、区间两端、正负堆叠、类别顺序 |
| 3 组合与统计 | `common` → `waterfall` → `histogram` → `boxPlot` → `heatmap` → `mosaic` | 共享/独立轴、多个系列与区域、累计值、区间宽度、箱须、格网及可变带宽 | 柱线组合、双轴、总计柱、不等宽区间、异常点、空单元 |
| 4 极坐标与指标 | `pie` → `rose` → `radar` → `linearProgress` → `circularProgress` → `gauge` → `liquid` | 弧、环、径向比例尺、轨道、静态液面 | 饼/环、起止角、径向刻度、进度极值；液面固定静态状态 |
| 5 专用几何 | `funnel` → `treemap` → `sunburst` → `circlePacking` → `sankey` → `correlation` → `venn` | 按图种补梯形、层级、流量、关系及集合算法 | 层级包含、节点边界、连线宽度、集合交集，逐项比较几何 |
| 6 地图与文字 | `map` → `wordCloud` | 本地地理数据、投影、路径；固定字体、词布局及随机源 | 多边形与孔洞、无匹配区域；词边界、旋转和可重复输出 |

扩展包和统计绘图包分别维护清单，使用[上游类型名录](CHART_TYPES.md)登记。核心路径稳定后，扩展按前置能力推进：金融和转化漏斗 → 静态时间/序列图 → 图形与图像。排名、序列故事类仅在可定义上游单幅静态结果时纳入；播放效果排除。统计图按“统计输入 → 核心 spec → 已验收系列”迁移，每个规格先比编译输出再比画面。扩展和统计图的条目独立于核心完成数。所有 3D 图表、三维系列、坐标轴和投影均排除。二维词云继续纳入核心图表验收。
