# 开发工作指南

当前规则摘要见 [AGENTS.md](../../AGENTS.md)；来源/图像对照细节见[移植规程](../PORTING_WORKFLOW.md)。用户用法见[用户目录](../README.md)。

## 按任务阅读

先查 `git status`，确认当前范围、owner 和授权动作。不要恢复旧发行/迁移任务。
版本查 `pyproject.toml`，运行状态查当前任务引用的机器记录。原有发行说明只描述其历史版本。
文档任务核真实公开 API、字段、默认值、资源和导出，不重新安装或制作整轮图表基准。
实现任务从固定原版的 spec transformer、数据、series、mark、组件追到 Python 消费者。

## 实现与来源

生产走公开 `py-skia-canvas` 与纯 Python/NumPy 算法，不运行 JS/DOM、浏览器或私有表面后备。
可选 reference 路径专供旧字形回归，与默认 Canvas 的环境和结果分别记录。
移植算法、数据、配色和资源核对版本/来源与许可证，不能把本地缓存当发布依赖。
跨文件/跨仓变更协调 owner；公共资源/几何/API变更先明确合同及消费者。
Canvas/字体对象留在创建线程；公开 scene 与跨线程数据不泄漏原生对象。
图种和字段未支持时明确诊断，不通过替图种、删数据、固定坐标或空白成功图规避。

## 独立验证

参考规格与预期从固定源及独立推导建立；不得以 Python 当前输出充当原版。
先保留完整首次失败，再批修根因，最后对同一候选运行相关与必要全量回归。
记录实际命令、环境、来源/输入/候选指纹、退出码、原图、scene 和差异；已闭合运行不覆盖。
图像比较保原尺寸/原字节，不通过缩放/遮罩/模糊掩盖内容错误。
人工核值、文字、轴、关系、图例、裁切、重叠和可读性；trace存在不等于实际可见。
字体/栅格/自然几何差异按事实说明，不推导完整 JS 兼容率，不批量放宽门禁。
相关组通过后按影响面决定共享/全量测试；发行安装结果与工作区结果分别记录。

## 完成和授权

完成说明改动、实测结果、未执行检查与实际限制；历史验收不能自动授予新候选通过。
用户首页聚焦使用；来源、计划、证据、发行和法律资料在[开发索引](README.md)分类保留。
保留脏树和既有原始基准。本地可逆准备和必要检查按任务自主执行，纯文档修改不额外触发安装或构建。提交、推送和发布依据当前用户授权，不由旧记录扩大权限，也不重复请求已有授权。
